# Домен printvibe.by и автовыкладка

Сайт работает на https://printvibe.by/ (хостинг hoster.by).  
После каждого пуша в `main` GitHub Actions собирает статику и заливает её по FTP.

Не юридическая консультация: пункты про закон проверить у юриста.

## Как устроена выкладка

1. Пуш в ветку `main` (или ручной запуск workflow **Deploy**).
2. GitHub ставит зависимости, собирает сайт с базой `/`.
3. Готовые файлы из `dist/client/` уходят по FTP (по одному файлу, с повторами) в домашнюю папку FTP-пользователя (`/www/printvibe.by`).
4. Через пару минут обновления видны на https://printvibe.by/

Пароль FTP в коде и в git **не хранится** — только в секретах репозитория.

## Один раз: секреты GitHub

Нужен FTP-пользователь из панели hoster.by (у вас это `h220448_printvibe`, папка `/www/printvibe.by`).

1. Открой https://github.com/IlyaSenkevich19/printvibe-landing/settings/secrets/actions  
   (Settings → Secrets and variables → Actions).
2. **New repository secret** — создай три секрета:

| Имя секрета     | Значение                                      |
| --------------- | --------------------------------------------- |
| `FTP_SERVER`    | `vh167.hoster.by`                             |
| `FTP_USERNAME`  | `h220448_printvibe`                           |
| `FTP_PASSWORD`  | пароль этого FTP-пользователя из панели       |

3. Если пароль не помнишь: панель hoster → **FTP-пользователи** → `h220448_printvibe` → задай новый пароль → тот же пароль в секрет `FTP_PASSWORD`.

После сохранения секретов сделай пустой пуш или Actions → **Deploy** → **Run workflow**.

## SSL

Бесплатный **Let's Encrypt** в панели hoster.by. Платный GlobalSign не нужен.  
Если браузер пишет Not Secure, а в инкогнито всё ок — очисти данные сайта `printvibe.by` в Chrome.

## Локальная проверка сборки как на сервере

```bash
GITHUB_PAGES=true PAGES_BASE=/ yarn build
```

Готовые файлы будут в `dist/client/`.
