## Локальный запуск

```sh
nvm use          # .nvmrc = 22. На Node 20.10 Vite 8 падает (styleText / rolldown bindings)
yarn             # если node_modules ставились на другой версии Node — удалить и поставить заново
yarn dev         # http://localhost:8080/
```

Если `yarn` не находится: один раз `corepack enable`. Перед пушем хук `.githooks/pre-push` запускает `yarn verify` (типы и линтер). На GitHub Actions при пуше в `main` только сборка и публикация, без повторных проверок. После билда удалять `.output`.

В `tsconfig` включены `noUncheckedIndexedAccess` и `exactOptionalPropertyTypes` — для опциональных пропсов, которым передаётся `undefined`, писать `T | undefined`.

## Стек

TanStack Start (SSR) + TanStack Router (file routes, `routeTree.gen.ts` генерится dev-сервером) + React 19 + Tailwind CSS v4 + Vite 8. Плагины собраны в `vite.config.ts`. Обычная сборка — Nitro `node-server`. Превью без своего домена — GitHub Pages: workflow `.github/workflows/pages.yml` при `GITHUB_PAGES=true` пререндерит `/` и `/privacy` в статику и публикует ветку `main` на `https://ilyasenkevich19.github.io/printvibe-landing/`. Типы и линтер на GitHub не гоняются.

## Дизайн-система

- Концепция — **типография/печать**, не «абстрактный креатив»: бумага + краска, метки обреза, цветовая шкала CMYK, растр (halftone), несовмещение красок, «печатная голова».
- Цвета (oklch в `styles.css`): `paper`, `paper-deep`, `ink`, `violet` (из логотипа), `orange` (из логотипа). **Оранжевый не использовать для мелкого текста на светлом фоне** — не проходит контраст; только заливки/крупный текст, текст поверх — `ink`.
- Шрифты (self-hosted, только latin + cyrillic, ~98 КБ): Dela Gothic One — заголовки, Onest — текст, JetBrains Mono — технические подписи (`.eyebrow`).
- Мотив из логотипа — скошенная плашка (`.plate`). Кнопки `.btn-primary/.btn-ghost/.btn-orange` со смещённой тенью.
- Анимации: несовмещение красок в H1, «печать» карточек в hero, вращающаяся печать, бегущая строка. Анимаций, привязанных к прокрутке, нет: блоки не двигаются при скролле. Всё отключается при `prefers-reduced-motion`.
- Пользователь просил: **без AI slop** (никаких генерических градиентов/glassmorphism/эмодзи, выдуманных цифр и отзывов).

### Известные грабли

- Свои CSS-классы в `styles.css` вне `@layer` перебивают утилиты Tailwind. Не задавать в них `position`/`display` — так уже ломались `.print-in` и `Stamp`.
- У `logo.png` белый (не прозрачный) фон — в `Logo` стоит `mix-blend-multiply`. Нужен прозрачный PNG/SVG логотипа от владельца.
## Ключевые фичи

- **Карточки услуг** — картинки видны сразу (пользователь просил: не прятать за hover). Кнопка «Примерить свой дизайн» переключает примерочную.
- **Примерочная** (`TryOn.tsx`) — загрузка картинки, SVG-макеты футболки/худи/кружки/наклейки, цвет. Рамка как в Paint: принт двигается за тело, уголки меняют ширину и высоту по отдельности, противоположный угол остаётся. Ползунки «Ширина», «Высота», «Слева», «Сверху» задают то же самое. На майке и худи принт рисуется поверх фактуры ткани, без затемнения, чтобы фото было таким же ярким, как на кружке. Превью примерочной прокручивается вместе со страницей. У футболки и худи есть грудь и спина. Файл не уходит на сервер (object URL). Кнопка выбора файла — обычный `<input type="file">` в потоке, без `<label>`: кнопка стилизована, рядом превью выбранной картинки и «Убрать макет». Дисклеймер «визуализация примерная».
  - Форматы: JPG/PNG/WEBP/SVG — с превью. HEIC/HEIF конвертируются в браузере через `heic-to` (LGPL-3.0, ленивый чанк ≈3 МБ, только если выбран HEIC); в интерфейсе просим JPG/PNG. PDF/AI/EPS/PSD/CDR/TIFF принимаются без превью, отправляется оригинал.
  - Кнопка заказа в примерочной: PNG-превью рендерится заранее без рамки и уголков выбора (debounce 350 мс), потому что `navigator.share` с файлами должен вызываться синхронно в обработчике клика (иначе Safari отказывает). Если браузер умеет делиться файлами, кнопка «Отправить макет в Telegram» открывает системное «Поделиться» (превью + оригинал + текст заказа). Иначе кнопка называется «Открыть Telegram с заказом»: скачивается превью, открывается чат `@ilw_dtl`, текст копируется в буфер, под кнопкой заранее сказано, что файл нужно прикрепить вручную.
  - Telegram-бот (автоматическая отправка заявки владельцу) — **отложен**, пока владелец не создаст бота. План: серверная функция TanStack Start с токеном только на сервере, форма с согласием на обработку ПД, обновить `/privacy` (появится реальный сбор данных).
- **Галерея работ** (`Cases.tsx`) — фильтры по изделиям, лайтбокс на `<dialog>` (стрелки, Esc). Пока реальных фото нет, секция не обещает галерею на сайте и ведёт в Instagram. Демо-картинки только в `DEV`.
- Карта Яндекса — фасад, iframe грузится **только по клику** (нет сторонних cookies → не нужен cookie-баннер).
- Мобильная нижняя панель: Telegram / Позвонить / Маршрут. На компьютере в шапке повторяется кнопка «Написать в Telegram». Статус «открыто» — на первом экране и в контактах, подсветка текущего дня там же.

## Фото работ — как добавлять

- Instagram без логина не отдаёт посты (API и embed требуют авторизацию). **В аккаунт друга не входить** — нет пароля и риск блокировки. Фото должен прислать владелец.
- Класть в `src/assets/cases/`. Префикс имени = категория: `tshirt-*`, `hoodie-*`, `mug-*`, `sticker-*`, `photo-*`, прочее → «Другое». Подписи — опционально в `captions` в `src/content/cases.ts`.
- Пока папка пуста: в dev показываются 4 демо-картинки без плашки, **в продакшене демо не попадает** (секция показывает только CTA на Instagram).
- Текущие `src/assets/work-*.jpg` — **AI-сгенерированные иллюстрации, не реальные заказы.** Используются как иллюстрации услуг; выдавать их за «примеры работ» нельзя. Заменить реальными фото, когда будут.

## SEO / GEO

- `lang="ru"`, один title/description на страницу, canonical, Open Graph (`og:locale ru_BY`, `og-image.jpg` 1200×630), geo-meta.
- JSON-LD в `head().meta` через `{ "script:ld+json": ... }` (TanStack). Дочерний route перекрывает `title` и `meta` корня; `links` **не дедуплицируются** → canonical только в дочерних роутах.
- `robots.txt` явно разрешает Яндекс, Google, GPTBot, OAI-SearchBot, PerplexityBot, ClaudeBot, Google-Extended.
- `llms.txt` — выжимка о бизнесе для AI-поиска. FAQ с FAQPage-разметкой — главный GEO-актив; ответы только из подтверждённых фактов.
- `SITE_URL = https://printvibe.by` — **домен не подтверждён** (сейчас не резолвится). При смене обновить `business.ts`, `robots.txt`, `sitemap.xml`, `llms.txt`.
