# Запуск сайта на своём домене

Пошаговый план, как перевести сайт PrintVibe с временного адреса
`https://ilyasenkevich19.github.io/printvibe-landing/` на `https://printvibe.by`.

Не юридическая консультация: пункты про закон проверить у юриста.

## Коротко

| Что | Кто делает |
| --- | --- |
| Решить, где будет храниться сайт (хостинг) | Владелец |
| Купить домен `printvibe.by` | Владелец |
| Прислать ФИО ИП (или название фирмы) и УНП | Владелец |
| Настроить сборку, домен, HTTPS, проверить сайт | Разработчик |
| Подключить Яндекс Вебмастер и Google Search Console | Разработчик вместе с владельцем |

## 1. Домен

- `printvibe.by` на 15 октября 2026 свободен (проверено через whois.cctld.by: «object does not exist»). Пока его никто не занял, лучше купить сразу.
- Домены `.by` продают аккредитованные регистраторы, например [hoster.by](https://hoster.by) или [domain.by](https://domain.by).
- Регистрировать на ИП или фирму, через которые работает салон, а не на частное лицо или разработчика. Так домен юридически принадлежит бизнесу.
- Доступ от личного кабинета регистратора хранить у владельца. Разработчику нужен только доступ к настройкам DNS, или владелец по инструкции добавит записи сам.

## 2. Хостинг: где будет лежать сайт

Сайт после сборки — это обычные файлы (HTML, картинки, скрипты), отдельный сервер с базой данных не нужен. Поэтому подойдёт самый простой хостинг.

### Вариант А. Хостинг в Беларуси (рекомендуется)

По Указу № 60 сайты, через которые ИП и фирмы Беларуси продают товары и услуги, должны размещаться на хостинге в Беларуси. Салон принимает заказы через сайт, поэтому правило, скорее всего, касается и его — уточнить у юриста.

- Пример: [hoster.by](https://hoster.by), там же можно купить домен.
- Хватает самого простого тарифа для сайтов с доступом по FTP или SFTP.
- Как будет работать: после каждой заливки в GitHub сборка сама загрузит новые файлы на хостинг. Для этого владелец передаёт разработчику данные доступа по FTP/SFTP, а разработчик сохраняет их в секретных настройках репозитория. В коде пароль не хранится.

### Вариант Б. GitHub Pages со своим доменом (временно)

- Бесплатно и быстро: сайт уже работает там, нужно только привязать домен.
- Минус: серверы не в Беларуси, поэтому для продаж через сайт это, скорее всего, не подходит под Указ № 60. Годится как временное решение, пока выбирается хостинг в РБ.
- Политику конфиденциальности тогда нужно дополнить: сайт обслуживает GitHub (США).

## 3. Что сделает разработчик

1. Переключит сборку с адреса `/printvibe-landing/` на корень домена `/`.
2. Настроит автоматическую выкладку на выбранный хостинг (вариант А) или привязку домена в GitHub Pages (вариант Б).
3. Даст владельцу DNS-записи, которые нужно добавить у регистратора домена, или добавит их сам.
4. Включит HTTPS (замочек в браузере) и переадресацию с `http://` и `www.` на `https://printvibe.by`.
5. Проверит адрес `https://printvibe.by` во всех файлах сайта: `src/content/business.ts`, `public/robots.txt`, `public/sitemap.xml`, `public/llms.txt`.
6. Проверит на настоящем домене:
   - главная, политика конфиденциальности, все ссылки и кнопки;
   - страница 404 для несуществующих адресов;
   - работа сайта без интернета;
   - примерочная и отправка заказа в Telegram;
   - вид в превью ссылок (Telegram, Instagram).
7. Добавит сайт в [Яндекс Вебмастер](https://webmaster.yandex.ru) и [Google Search Console](https://search.google.com/search-console), отправит туда карту сайта. Для подтверждения прав нужен вход в аккаунты владельца.
8. Обновит README: основной адрес сайта вместо временного.

## 4. Что нужно от владельца

1. **Решение по хостингу**: вариант А или Б.
2. **Купленный домен** `printvibe.by` и доступ к его DNS-настройкам.
3. **Данные исполнителя**: ФИО ИП (или полное название фирмы) и УНП. По закону они должны быть на сайте. Сейчас эти поля пустые, и сайт их не показывает. Заполняются в `src/content/business.ts`, поле `legal`.
4. Для варианта А — **доступ к хостингу по FTP/SFTP**: адрес сервера, логин, пароль. Передавать лично или в мессенджере, не в общих чатах.
5. Аккаунты Яндекса и Google, на которые записать сайт в поисковиках.

## 5. Желательно до запуска

- Заменить иллюстрации в разделе работ на реальные фото заказов: сейчас там картинки, сгенерированные нейросетью, выдавать их за свои работы нельзя.
- Временный адрес на GitHub Pages после переезда можно оставить или выключить, чтобы поисковики не видели две копии сайта.
