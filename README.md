# PrintVibe

Лендинг салона печати PrintVibe в Гомеле: футболки, худи, кружки, наклейки и печать фото.

Сайт в интернете (превью без своего домена): https://ilyasenkevich19.github.io/printvibe-landing/

## Как запустить сайт у себя на компьютере

Это нужно, чтобы посмотреть сайт до публикации. Шаги 1–4 делаются один раз, минут 10. Дальше хватит шага 5.

### 1. Установите Node.js

Это программа, на которой работает сайт.

1. Откройте https://nodejs.org/
2. Скачайте версию **22 LTS**: она подписана «LTS», если на сайте стоит другая версия, выберите 22 в списке.
3. Установите как обычную программу: «Далее», «Далее», «Готово».

### 2. Установите git

Это программа, которая скачивает код сайта и потом его обновляет.

- **Mac:** откройте программу «Терминал» (Cmd+Пробел, напишите «Терминал»), введите `git --version` и нажмите Enter. Если git нет, Mac сам предложит установить «инструменты командной строки» — согласитесь и дождитесь конца установки.
- **Windows:** скачайте установщик с https://git-scm.com/download/win и установите, везде оставляя настройки по умолчанию.

### 3. Откройте терминал

- **Mac:** программа «Терминал» (Cmd+Пробел, напишите «Терминал»).
- **Windows:** Пуск → напишите «Терминал» или «PowerShell» → откройте.

Если терминал был открыт до установки Node.js или git, закройте его и откройте заново.

### 4. Скачайте код сайта и подготовьте его

Скопируйте команды в терминал по одной и нажимайте Enter после каждой:

```sh
git clone https://github.com/IlyaSenkevich19/printvibe-landing.git
cd printvibe-landing
corepack enable
yarn
```

Что они делают: первая скачивает код в папку `printvibe-landing` (она появится в вашей домашней папке), вторая переходит в эту папку, третья включает Yarn, программу для установки частей сайта, четвёртая скачивает эти части, 1–3 минуты. Предупреждения жёлтым цветом (`warning`) — это нормально.

### 5. Запустите сайт

Каждый раз, когда хотите посмотреть сайт, откройте терминал и выполните:

```sh
cd printvibe-landing
git pull
yarn
yarn dev
```

`git pull` скачивает последние изменения, `yarn` доустанавливает новые части, если они появились (обычно проходит за пару секунд), `yarn dev` запускает сайт.

Когда в терминале появится адрес, откройте в браузере http://localhost:8080/

Терминал не закрывайте, пока смотрите сайт. Остановить: в окне терминала нажмите **Ctrl+C**. Это одинаково на Mac и Windows.

### Если что-то не работает

- **`command not found: yarn` или «yarn не является командой»** — не выполнена команда `corepack enable`. Выполните её ещё раз. На Windows, если пишет про доступ, откройте терминал от имени администратора: Пуск → «Терминал» → правой кнопкой → «Запуск от имени администратора».
- **`command not found: node` / `git` или «node / git не является командой»** — программа не установлена, или терминал открыт до установки. Закройте терминал, откройте заново.
- **`destination path 'printvibe-landing' already exists`** — код уже скачан раньше. Скачивать заново не нужно, переходите к шагу 5.
- **`cd: no such file or directory: printvibe-landing`** — терминал открылся не в домашней папке. Выполните `cd ~` и повторите.
- **Ошибки про `styleText`, `rolldown` или `bindings`** — стоит старый Node.js. Проверьте командой `node -v`: должно начинаться с `v22`. Если нет, установите 22 с nodejs.org. Потом удалите папку `node_modules` внутри папки сайта и снова выполните `yarn`.
- **`Port 8080 is in use`** — сайт уже запущен в другом окне терминала. Найдите то окно и нажмите Ctrl+C, или просто откройте http://localhost:8080/.
- **На странице что-то старое** — обновите страницу без кэша: Cmd+Shift+R на Mac, Ctrl+F5 на Windows.

## Где что менять

Телефон, Telegram, Instagram, адрес и часы работы лежат в одном файле: `src/content/business.ts`. Там же тексты частых вопросов. Сохраните файл, и запущенный сайт обновится сам.

## Для разработчика

```sh
nvm use      # Node 22 из .nvmrc
yarn
yarn dev     # http://localhost:8080/
```

Перед пушем хук запускает `yarn verify` (типы и линтер). В новом клоне хук ставится один раз: `cp .githooks/pre-push .git/hooks/pre-push && chmod +x .git/hooks/pre-push`.

На GitHub при пуше в `main` код только собирается и публикуется на GitHub Pages, без повторных проверок.
